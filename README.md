# 坦克大战 (Tank Battle)

一个使用纯 HTML/CSS/JavaScript 实现的经典坦克大战游戏。

## 功能特点

- 🎮 经典坦克大战玩法
- 🧱 可破坏和不可破坏的墙壁
- 🤖 AI 敌方坦克
- 💥 爆炸粒子特效
- 🛡️ 护甲和加速道具
- 📱 支持手机触屏操控
- 🎯 关卡递增，难度逐渐提升

## 操作方式

### 键盘
- **方向键 / WASD** — 移动坦克
- **空格键 / J** — 发射子弹

### 手机
- 屏幕上的虚拟按钮操控

## 快速开始

直接用浏览器打开 `index.html` 即可开始游戏。

或者使用本地服务器：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 游戏截图

启动游戏后你将看到：
- 绿色坦克为玩家
- 红色坦克为敌人
- 棕色砖墙可被子弹摧毁
- 灰色钢墙无法摧毁
- 蓝色护甲道具 🛡
- 绿色加速道具 ⚡
